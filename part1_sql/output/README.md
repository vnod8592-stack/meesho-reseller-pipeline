# Part 1 SQL Outputs

This folder contains the CSV results generated from the SQL business queries.

## Output Files

- `monthly_category_revenue.csv` — monthly revenue by category
- `region_revenue.csv` — revenue by region
- `top_resellers.csv` — top 5 resellers by total spend
- `zero_order_resellers.csv` — resellers with no orders
- `aov_june.csv` — June delivered Average Order Value

The files are generated from the SQLite database using the SQL queries in `part1_sql/queries.sql`.
